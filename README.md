# PastaClient (Fabric 1.16.5)

Збірка: JDK 17 + Gradle 7.3.3 -> `gradle build` (або GitHub Actions), jar у build/libs/pastaclient-1.0.0.jar.
Потрібні Fabric Loader + Fabric API 0.42.0+1.16.

Right Shift - ClickGUI (ЛКМ вмик/вимк, ПКМ налаштування, СКМ клавіша), End - вимкнути все.
Custom HUD (Render): Watermark (лого), Keystrokes (WASD/SPACE/LMB/RMB), TargetHUD (HP цілі), HitEffects, TargetESP.
